# 🛒 Amazon Clone

A full-stack e-commerce application replicating Amazon's core shopping experience — featuring product browsing, cart management, checkout with Stripe, Firebase authentication, and CI/CD deployment via GitHub Actions.

## ✨ Features

- **Product Browsing** — Browse and filter products across categories
- **Shopping Cart** — Add, remove, and update item quantities with persistent state
- **Checkout & Payments** — Secure payment processing via Stripe
- **Authentication** — Firebase Auth with Google sign-in
- **Order History** — View past orders tied to your account
- **CI/CD Pipeline** — Automated deployment to Firebase Hosting via GitHub Actions

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React (Create React App) |
| Auth & Database | Firebase |
| Payments | Stripe |
| Deployment | Firebase Hosting + GitHub Actions |
